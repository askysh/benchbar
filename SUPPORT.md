# Getting help

- **A question** (how to do something, whether a behaviour is expected):
  [Discussions, Q&A](https://github.com/askysh/benchbar/discussions/categories/q-a).
- **A bug:** run `benchbar doctor` and `benchbar report`, then open the
  [bug form](https://github.com/askysh/benchbar/issues/new?template=bug_report.yml)
  (macOS and Linux) or use Report a Bug in the Windows tray.
- **A wrong or missing docs page:** the "Report a problem with this page"
  link at the bottom of every page of the docs opens a form with the page
  address filled in.
- **A security problem:** a private report, never a public issue. See
  [SECURITY.md](SECURITY.md).

Known problems and their workarounds are in
[Known issues](https://benchbar.akashmishra.com/troubleshooting/#known-issues).
Every new issue gets a first reply within two days (CONTRIBUTING.md,
Issues), even if it is only "seen".
