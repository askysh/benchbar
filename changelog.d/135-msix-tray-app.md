### Windows tray

- In a Microsoft Store (MSIX) package the tray starts at sign in through the package's startup task and never touches the Startup folder. It offers no update check or banner (the Store updates it), Settings shows the `benchbar.exe` alias path, Windows starts the tray again after an update, and a notice says when the one line installer's copy is also on the PC. Nothing is published to the Store in 0.9.0, and nothing changes for the one line installer's copy.
