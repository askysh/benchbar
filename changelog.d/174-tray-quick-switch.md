### Windows tray

- The tray menu has **Quick Switch...**: a small panel that opens a site signed in as Administrator, a pinned user or a user found by typing, with the arrow keys, Enter and the digits 0 to 9. **Pin** in Find User keeps up to nine users per site. It only works on a site where you turned Open as on, and it says why when there is nothing to open (#174).

### Docs

- The Windows guide and the features table describe Quick Switch and pinned users (#174).
