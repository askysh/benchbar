### Windows tray

- The bench page has a **Sharing** tab while the "Share with people on the same Wi-Fi" experiment is on: start and stop a room, extend or lock it, show and copy the room code and the invite, see the checks and the people in the room and remove one, with the Mac app's questions. The tab reads when it opens and changes nothing by itself. Setting up the copy and the network protection stay in PowerShell for now, and joining a room as a guest is not on Windows yet (#174).

### Docs

- The Windows guide describes the Sharing tab and says why joining a room is not there (#174).
