### Windows tray

- A site's menu in the Sites tab has **Allow Open as...** (the Mac app's question first, never turned on by the tray itself) and **Turn Off Open as**. While it is on, **Open as...** lists the site's users with a search and opens the site in your browser signed in as one of them. `benchbar.exe` opens the browser, so the sign in link never reaches the tray (#174).

### Docs

- The Windows guide and the features table describe Open as in the Sites tab (#174).
