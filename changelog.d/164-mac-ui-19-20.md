### Mac app

- A bench's site list is worked out once when its summary or status changes, not on every read by a view, and the sidebar finds benches with the same name in one pass (UI-20, part of #164).

### For contributors

- The Mac app's tests wait for a condition with a deadline instead of fixed sleeps (file watcher, log tailer, speed loop, the CPU probe), and the clock conversion test no longer depends on machine speed. CI sets `BENCHBAR_REQUIRE_INTEROP`, so the Swift to Node share interop tests fail when node is missing instead of being skipped. They also work again with a node that prints a TAP header on stdout (UI-19, part of #164).
