### Sharing

- The Windows tray can join a room: on the Sharing tab, "Join a room..." takes the
  host's address, shows the room and the 16 digits of the host's key, and asks for the
  room code only after that. It waits for the seat where the host gives them out, with
  a Cancel, and lists the rooms this computer joined with Open, Leave and Forget
  (Forget asks first). The room code goes to the command line tool on its standard
  input and is never saved (#174).
