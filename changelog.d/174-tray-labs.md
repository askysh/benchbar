### Windows tray

- The BenchBar window has a **Labs** page. It lists the experiments from `benchbar.exe labs list` with a switch, the warning and the version of each, and turns one on or off with the same calls as the Mac app. An experiment that is not on Windows yet stays off and says why (#174).

### Docs

- The Windows guide says that the BenchBar window has a Labs page, and the features table lists it (#174).
