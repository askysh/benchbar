### Command line

- The `benchbar` Homebrew formula installs on Linux (Linuxbrew) too: `brew install askysh/tap/benchbar`. It adds `git` and `curl` there, uses the same state folder as the one line installer, and `benchbar self-update` upgrades it with brew. The app cask stays macOS only (#176).
